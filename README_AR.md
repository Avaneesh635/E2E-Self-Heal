### ما هو E2E-Self-Heal؟

E2E-Self-Heal هو محرك ذكي يقوم تلقائياً بإصلاح اختبارات Playwright المعطلة. عندما تفشل اختباراتك بسبب تغير المحددات (Selectors) أو تغير واجهة المستخدم، يقوم المحرك بتحليل فشل الاختبار، وفهم git diff، واقتراح إصلاح تلقائي باستخدام LLM.

### الميزات الرئيسية

- **إصلاح تلقائي للمحددات:** يصلح محددات CSS و XPath التي تغيرت.
- **إصلاح الانتظار الذكي:** يضيف عمليات انتظار صحيحة تلقائياً.
- **تحليل Git Diff:** يفهم ما الذي تغير في الكود الأخير.
- **مدعوم بأي LLM:** يعمل مع OpenAI, Claude, Gemini عبر OrcaRouter.
- **آمن:** يصلح المحددات والانتظارات فقط.

### كيف يعمل

1. التشغيل: يتم تشغيل اختبار Playwright ويفشل.
2. الالتقاط: يقوم المحرك بالتقاط لقطة فشل وتتبع المكدس.
3. التحليل: يتم إرسال البيانات إلى LLM لتحليل السبب الجذري.
4. الاقتراح: يقترح LLM تصحيحاً للاختبار.
5. التحقق: يتم تشغيل الاختبار المصحح مرة أخرى للتأكد من نجاحه.
